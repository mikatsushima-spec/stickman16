# stickman16

スマホで遊べる棒人間探しゲーム。5分で16人の静止した棒人間を見つけます。

## Androidへのインストール
GitHub Pagesでmainブランチのルートを公開後、Chromeで公開URLを開き、メニューから「ホーム画面に追加」→「インストール」を選びます。

## 構成
- index.html: ゲーム本体（簡易イラスト背景版）
- manifest.webmanifest: PWA設定
- sw.js: オフラインキャッシュ
- icon.svg: アプリアイコン

以前の写真風背景を埋め込んだHTML版とは別の、GitHubで管理しやすい軽量版です。
